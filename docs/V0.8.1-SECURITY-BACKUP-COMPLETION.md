# v0.8.1 Security & Backup Completion Record

## Secure accounts

- One secure login for Owner, Office, Crew and Customer.
- No shared role password and no packaged default Owner password.
- First-run Owner initialization at `/login`.
- Passwords use salted scrypt hashes and are never stored as plaintext.
- Authenticated sessions use HttpOnly, SameSite=Strict cookies; production cookies are Secure.
- Owner can create users and issue 72-hour activation/reset links.
- Crew and Customer records are linked to the appropriate team/customer identifiers.
- Server-side authorization blocks roles from data they do not own or need.
- Crew bootstrap is limited to assigned job/customer/photo information and excludes invoices, payroll, expenses and company-wide datasets.
- Customer bootstrap is limited to its linked customer account, invoices and requests.
- Full backup export/restore, hosted backup status and device-key creation are Owner-only.

## Hosted and Windows backup

- Hosted snapshot archive runs independently of the Windows PC.
- Retention: 30 daily snapshots, 12 weekly snapshots and 12 monthly snapshots.
- `BACKUP_ARCHIVE_DIR` can point to the persistent hosted storage location selected for production.
- Owner can create a hashed Backup Device Key for a Windows backup computer.
- `START-BACKUP-COMPANION.bat` runs the local companion.
- On first run, the companion asks for hosted URL, Device Key and one or more backup folders/drives; no local path is hard-coded.
- If one configured destination is unavailable, available destinations still receive the backup.
- When the PC returns after being off, the companion downloads the newest hosted full backup and saves it to configured destinations.

## Billing corrections included during completion

- Monthly work completed after the customer billing day is assigned to the next monthly billing cycle rather than invoicing immediately.
- Invoice overpayments apply only to the selected invoice balance and cannot erase unrelated open receivables.
